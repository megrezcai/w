Shotcut 表面贴字 · Windows x64 测试版

1. 完整解压本包，不要在压缩包内直接运行。
2. 关闭 Shotcut，双击 Install-Plugin.cmd，选择 shotcut.exe。
   推荐使用解压在可写目录的官方 Shotcut 便携版。
3. 双击 Start-Assistant.cmd，浏览器会打开中文操作界面。
4. 打开视频，选清晰帧，依次点表面：左上、右上、右下、左下。
5. 保存四角参考帧，输入字幕，点击自动跟踪。
6. 预览后下载工程 ZIP，完整解压，用 Shotcut 打开 surface-text.mlt。

本包已包含本地 Python 和依赖，无需安装开发工具或联网。
先下载结果，再按 Ctrl+C 正常退出。强行关闭窗口可能留下临时文件。
字幕在 V2 独立透明轨道，V1 保留原视频和声音。
改文字请回助手重新生成；四角关键帧可以在 Shotcut 修改。

适用于立体物体的单个平面，不适用于球面、圆柱或跨过盒子棱角。
严重遮挡或模糊可能跟踪丢失，请添加清晰参考帧作为修正点。
不包含前景遮挡分割、自动去除原文字、HDR 或自动光照匹配。

已在 Linux 验证算法、浏览器流程、原生滤镜与 Shotcut 界面。
Windows DLL 已编译，但 Windows 安装和运行尚未实机验收。
完整能力、限制、源码和删除方法见 README.md。
